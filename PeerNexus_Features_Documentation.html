PeerNexus (CampusForge)

Comprehensive Platform Features & Technical Functionalities Specification

Target Audience: B.Tech Computer Science & Engineering Students, Academic Project Coordinators, Viva Evaluators, and Campus Lab Administrators.

1. Executive Overview & System Purpose

PeerNexus is an AI-powered, multi-tenant academic collaboration and skill-barter platform built for engineering students to solve key friction points in project formation, skill exchange, and lab resource access:

  • Non-Monetary Skill Exchange: Decentralized barter system using an automated Escrow Credit Economy (students teach to earn credits and spend credits to learn).
  • Capstone & Hackathon Team Recruitment: Role-based team assembly with automated candidate compatibility scoring.
  • CS Algorithm Visualizer for Viva Examinations: Interactive step-by-step inspector breaking down Jaccard Set Similarity and Mutual Complementarity matrix math for university evaluators.
  • Campus GPU Lab Reservations: Time-slot reservation system for NVIDIA A100 / RTX 4090 GPU workstations and campus technical workshops.
  • Real-Time Active Trade Session Rooms: WebRTC video conferencing, synthetic camera/audio equalizers (for offline demos), synchronized collaborative code scratchpad, and Gemini AI guidance.

3.2 Public Landing Page (LandingPage.jsx)

  • Dynamic live feature tab switcher (Skills, Projects, Matching, Labs).

3.3 Skill Barter Marketplace (SkillExchange.jsx)

  • Real-time search and domain category filtering.
  • Automated Escrow credit locking on trade request.
  • Publish new offers with +50 Cr reward.

3.4 Capstone Project Collaborator (ProjectCollaborator.jsx)

  • Mutual Complementarity Matrix: Bidirectional skill synergy evaluation.
  • Step-by-Step Viva Inspector: Dedicated mathematical walkthrough for faculty examiners.
